# 📱 ClientBank iOS — Мобильное приложение для iPhone

Полноценное нативное iOS-приложение клиентского банка на **SwiftUI** с поддержкой **бесконтактного входа в банкомат по Bluetooth (BLE)**, Face ID, переводами по номеру телефона и фирменной анимацией приветствия!

---

## ⚡ Главные возможности:
1. **Бесконтактный вход в банкомат по Bluetooth (BLE):**
   - Поднесите iPhone к банкомату — приложение на лету через `CoreBluetooth` находит банкомат поблизости, считывает код сессии и предлагает подтвердить вход в 1 касание (или по Face ID).
2. **Экран блокировки и Face ID:**
   - Ввод 4-значного ПИН-кода + вход по биометрии Face ID / Touch ID (`LocalAuthentication`).
3. **Фирменная анимация приветствия:**
   - Светлая карточка с крупным текстом `ДОБРЫЙ ДЕНЬ, <ИМЯ>!`.
4. **Переводы клиентам:**
   - Ввод номера получателя с моментальным авто-поиском имени (`Иван И.`), быстрые чипы сумм и списание в реальном времени.
5. **История операций:**
   - Пополнения, снятия, покупки и переводы с детализацией.
6. **Настройка адреса сервера:**
   - Шестерёнка на экране блокировки позволяет вписать локальный IP (`http://192.168.1.247:8000`) или ваш домен (`https://bank.domain.ru`).

## 🚀 Как собрать IPA через GitHub Actions:

1. **Создайте новый приватный репозиторий на GitHub** (например, `clientbank-ios`).
2. **Загрузите содержимое этой папки в репозиторий:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit ClientBank iOS"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/clientbank-ios.git
   git push -u origin main
   ```
3. **Сборка запустится автоматически:**
   - Перейдите во вкладку **Actions** в вашем репозитории на GitHub.
   - Сборщик запустит `Build iOS IPA` на виртуальной macOS-машине Apple (`macos-15`), сгенерирует Xcode проект через `xcodegen` и упакует `ClientBank.ipa`.
4. **Скачайте готовый IPA:**
   - По окончании сборки в разделе **Artifacts** появится архив **`ClientBank-IPA`**.
   - Скачайте его и распакуйте файл `ClientBank.ipa`.

## 📲 Установка на iPhone через Sideloadly:

1. Откройте **Sideloadly** на компьютере (ярлык уже есть на вашем рабочем столе!).
2. Подключите iPhone кабелем (или по Wi-Fi) к компьютеру.
3. Перетащите файл `ClientBank.ipa` в окно Sideloadly.
4. Введите свой Apple ID и нажмите **Start**.
5. На iPhone перейдите в:  
   *Настройки → Основные → VPN и управление устройством* → выберите ваш Apple ID и нажмите **«Доверять»**.
6. Приложение готово к использованию!
